that same competition's ranked detail removes it. The captured selected-board
consumer `590407.to` renders `e$`, which renders `eL`; `eL` passes the competition
unchanged to the imported `706615.H` selector and renders `590407.ee` when that
selector returns a target. The original DTO declares `phase`, `startsAt` and
`endsAt`, also exposed unchanged by the existing admitted native detail DTO.

This unit restores that missing mounted detail caller. The accepted #894 display,
digit boxes, selector, English-label adapter and timer implementation remain
unchanged. Open #1652 owns the separate expiry adapter proposal; this unit does
not change deadlines or infer a new competition phase. It does not recover the
hero video, original provider/cache, native-app promotion or backend semantics.
Captured materials retain their authorship; no additional whole-component or
milestone recovery is claimed.

`source-evidence.json` binds complete actual board/hero/copy nodes, their exact
value-passing calls, the imported helper and original DTO declaration slices to
three explicit capture contexts. The source verifier authenticates these bytes
and the unchanged accepted dependency hashes without executing captured bundles.
The normal check also verifies the native child is inside the admitted detail
branch and receives `data.competition`, rather than an inferred target.
