## Preserved behavior

- The default and invalid-input fallback is `table`; only the exact string
  `grid` selects grid. The source reader returns null for an invalid first
  matching cookie and does not continue to a later duplicate. URI errors
  propagate. The separate header parser defaults/normalizes as captured.
- The writer keeps path, one-year max-age, same-site and protocol-sensitive
  secure attributes. It does not itself validate/coerce a value; the descriptor
  and external setting framework own that preceding operation.
- `214100` uses an adapter-instance `Set` of subscribers. Write completes before
  notifications; a throwing writer prevents them. Duplicate listener identity,
  unsubscription, and thrown-listener iteration behavior are preserved.
- Radio selection uses `Object.is`. Clicking the already selected option still
  invokes the setter and writes/notifies. No language-selector-style unchanged
  guard is added. Plain-label compact/wrap and preview branches remain intact.
- The generic dispatcher calls its supplied setting hooks before hidden/custom
  branches, and keeps original description/compact/prepaint decisions. Its
  other controls remain ports rather than new product features.
