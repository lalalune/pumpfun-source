## Preserved full owner behavior

`disabled` fragment return. Disabled is a display branch, not authentication or
request admission. If it changes while local open state is true, the source
does not reset that state. The actual hover primitive's implementation and
policy remain external.

local open state and `{staleTime:300000}`. The inline summary key is
`['balanceSummary',address]`, enabled is `open && !!address`, and the complete
options set staleTime300000 before spreading optional queryOptions. The inline

`open && address.length>0`, retry1 and staleTime60000. Old query callbacks keep
captured URL/subject values. Neither callback forwards a query context signal.

- The financial normalization/projection API is required. Tests supply literal

## Reproduction and finite method

With existing pinned dependencies, from repository root:

```sh
node app/scripts/original-profile-hovercard.mjs --check
node --test app/tests/original_profile_hovercard.test.mjs
```

The producer parses original captures without execution and enforces canonical
UTF-8 client/contract bytes. Full source lexical statements are preserved:
X-link `W` is emitted with its witnessed original parent `let` declaration,
not an unbound assignment. Local `client.d.mts` types describe observed port
signatures; they are not original TypeScript, runtime validators or guarantees
about unacquired data.

Twelve model cases cover the complete used boundary and seven actual maintained
verifier rejections. The first model run passed2/failed10 because that generated
W declaration was missing `let`; exact initial generator/client/contract/types/
test bytes and failed output are retained privately for additive qualification.
The unchanged twelve cases pass after restoring the actual declaration. Virtual
child memo frames/state/effect/timer ports are explicit and do not establish
React scheduling or original provider parity.

The finite real React/compiler method is separate and frozen before execution:

```sh
node app/reconstruction/profile-hovercard/qualification/browser.mjs \
  --source FULL_FETCHABLE_SOURCE_COMMIT \
  --output "/tmp/profile hover fresh qualification"
```

It supplies all profile/query/financial/schema/display/clock/clipboard/renderer
capabilities. It makes no original profile, summary, PnL, auth or follow request.
The query port does not implement a cache/scheduler; the method explicitly
invokes its recorded source callbacks against in-memory readers. Clock callbacks
are advanced manually through a timer port:30s/2s registration/cleanup is
qualified, not wall-clock timing. Native button actions exercise the supplied
hover primitive; its500/100 delay arguments are checked, not implemented or
claimed as original pointer/delay behavior. Avatar and X metadata remain text/
attributes, no media or external link navigation. A pass requires explicit
receipts; this source README does not preclaim the pending run.

The host uses loopback-only GET HTML/bundle, restrictive CSP and external-request
blocking. It verifies four own runtime files against the selected Git commit,
records actual dependency/source hashes before/after and retains bundle/input/
result/trace outputs. It closes browser/host in finally. Source interval cleanup
is distinguished from host environment cleanup of the uncleaned feedback timeout.
No Next or actual clipboard service starts.
