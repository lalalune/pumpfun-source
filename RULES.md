# Community rules

This project was created by pump.fun and released to the community for educational purposes only.

- Contribute accurate on-chain Solana program source and validation tooling.
- Keep builds and tests reproducible, with documented inputs, commands and results.
- Do not capture or contribute pump.fun website, backend, API or other off-chain data or code.
- Do not contribute credentials, secrets or private data.
- Report validation results honestly and preserve existing correct behavior.

These community rules do not change the repository's MIT license.
