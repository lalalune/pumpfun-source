# Stable nearest handler context

The archived roadmap repeats named callers/callees at several depths and sorts
equal-depth set members without a deterministic tie-break. Generate a fresh
diagnostic packet through this source-bound successor:

```
python -B reconstruction/diagnostics/roadmap-stable-attribution/generate.py --output work/stable-attribution-new
python -B reconstruction/diagnostics/roadmap-stable-attribution/test_generate.py
```

The adapter retains the ten-level breadth-first graph boundary, keeps one minimum
distance per name and orders by distance then name. The reviewed archived source
is admitted by a fixed LF-normalized digest before loading. New packets bind
the raw source/adapter hashes and include that binding in their manifest.
Frozen root helpers, original captures and archived packets are unchanged.

Tests run the complete archived and adapted CLIs on real captures, verify every
window's minimum attribution, retain all other per-window fields, verify both
new packets and compare all files under two independent Python hash seeds.

These outputs retain the historical roadmap's other limitations, including its
old frontier estimates and planning heuristics. They are static named-context
diagnostics, not current task ownership, runtime reachability, matched-window
counts, semantic equivalence or security acceptance.
