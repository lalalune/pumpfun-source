# Feasible bounded replay, conditional claims

The plan is technically feasible. It is a plan, not an implemented or replayed
verifier, and this review authorizes neither. Exact original-byte authentication
plus a complete bounded control/direct-store walk can reproduce the stated
intraprocedural joins under the declared private-buffer, SBF ABI and valid-path
premises. Selected raw snippets alone cannot establish cross-region persistence.

The two value families are technically distinct. Selected K/C/N32 at
FP[-1408,-1376) supplies the four curve stores. Separately, meaningful incoming
N32 reaches caller Option33 at FP[-1617,-1584), R3 at+4a78, and helper Some
serialization into data[9,41). The last payload byte must remain part of the
last helper word. Reset/tag0 skips payload reads; tag2 skips the outer call.
Those absent payloads must never be interpreted as a selected or incoming key.
The endpoint is instruction-data construction and argument handoff, not successful
Fees state mutation. No original Rust type, private signature or lifetime follows.

Required implementation details, if root later authorizes implementation:

- Map original VAs through checked file-backed ELF ranges. Bind the original
  image, exact CTO27,400B and helper4,040B spans, all selected raw operands and
  call targets. Reject ambiguous mappings, malformed ranges, incomplete LDDW
  pairs and branches into continuation slots or outside the declared graph.
- Walk every instruction boundary in both fixed bodies for all encountered
  control-flow, direct-FP store and queried-register-definition classes. Decode
  known classes explicitly and refuse unsupported affecting instructions; an
  unknown opcode cannot silently mean harmless fallthrough or no write. Keep
  immediate and register stores at every width, actual byte overlap, exits and
  ABI call clobbers. This is a disclosed two-body scan, not whole-ELF disassembly.
- Derive predecessor/successor edges and every queried per-byte reaching writer.
  Admit the complete fixed query domain and all expected producer alternatives;
  do not permit shortened vectors or a printed result to stand in for a check.
  Trace each selected writer's value/register source as well as its address.
  A nearest-writer query alone proves no data value or path predicate.
- Query helper-frame pointer/length persistence through+998 too. The current
  authoring script runs CTO queries; its helper+2a8/+2a0 and+970/+978 checks are
  selected raw assertions, without an equivalent helper reaching-write query.
  Several sharing CTO queries also report writer sets without asserting an
  expected set. Future replay must enforce those relations itself rather than
  copy RESULT PASS wording or trust cache digests.
- Retain the all-call-return graph and its actual alternatives. It finds+3ea8
  for FP-2376 and+4070 for FP-2304 on paths through+26e0. Cut only the exact
  original+26e0/VA250f0 call after verifying its8 bytes and linked type10
  relocation/dynsym abort name. Document standard abort noreturn semantics as
  a premise. Preserve the uncut results; do not replace them with a blanket
  feasibility filter or silently cut other calls.
- The corrected graph still has legitimate sharing-register/writer alternatives.
  Bind their Some/reset/skip predicates to actual branches and producer values.
  Do not infer a meaningful N from an undefined reset payload or assume every
  graph route is feasible. Other calls retain conservative fallthrough and ABI
  clobbers; hidden indirect private-frame writes remain outside this direct
  analysis unless independently excluded.

The current plan properly says a cache hash is not a completeness proof and
offers a narrower selected-join fallback. That fallback must label inter-region
persistence as an external sealed assumption, rather than advertise the same
complete replay. Whole-body hashes authenticate bytes; they do not establish
operand interpretation, value-family names or memory semantics by themselves.

K/C/N, public new[1,33), account/curve roles and the invoke helper's semantic
name need the existing producer/public-ingress/helper-role witnesses. If a
future verifier does not independently byte-bind those minimal bridges, report
those labels as conditional on external sealed proofs. The proposed two-body
scan alone does not reprove the matched public wrapper's decoding. Similarly,
the known call target1a0530 is a raw target; calling it invoke_signed reuses
the existing raw-equal helper attribution. No additional helper body scan is
needed merely to claim argument handoff, provided that dependency is explicit.

Credit is appropriately bounded when stated as a replayable original join.
05e4f56a already supplies pre-fee selection, separate incoming-N producers,
packing and curve-phase anchors. PR3483 and prior helper/ABI work already
supply value-family corrections, candidate consumers and serializer format.
The possible addition is complete original producer-to-consumer byte joins,
including incoming N's final byte and explicit abort-qualified persistence.
It is not discovery of K/C/N, the helper format or a new source technique.
Event's live scope/overlap review, including PR3524, remains independent; this
technical review establishes no novelty or publication decision.

No technical blocker to planning was found. An implementation must satisfy
the obligations above before its claimed replay can be reviewed. The original
Error284 tail, arbitrary alias closure, unique function ownership/interior
entry absence, full runtime behavior, current S4 behavior and source gain all
remain outside the proposed contract. Existing failed selectors, conservative
output and hash-precondition correction must stay authenticated and unchanged.

This review read source text and cached JSON/metadata only. It did not read
the original ELF, execute a decoder or verifier, implement a verifier, run
compiler/scorer/normalizer/metric/VM/tests, or change source or remote state.
