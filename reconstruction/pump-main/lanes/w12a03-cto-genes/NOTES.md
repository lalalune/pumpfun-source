# Lane w12a03-cto-genes (wave 12, pool a): admin_cto gene harvest

Target: `0x22a10` `admin_cto::execute` (`programs/pump/src/creator/admin_cto.rs`), pinned at 27,400 B.
Base: main 20a1ae9c0 (programs/ unchanged through 241542515): admin_cto **0.43919** at 27,400 B, 3,352 slots,
1033/1033 normalized/raw. Angle: harvest every unlanded admin_cto mechanism from the dead x1/x2/y1/w9r2/w10r1
lanes, port each onto main as an individual gene, measure it alone, then beam-combine at exactly 27,400 B.

## Tools (this directory)

- `genes.py`: the gene catalog. Each gene is a list of exact `(old, new)` substitutions over main's
  `admin_cto.rs`; every substitution keeps the newline count, so every `require!`/`error!` site keeps its line.
  `SRC[name]` names the lane/branch each mechanism came from. `apply(text, [names])` composes genes in order.
  `python3 -I genes.py <admin_cto.rs>` checks that every gene applies.
- `qd.py`: queue daemon. Reads `$OUT/queue.txt` (`name=gene1+gene2+...`, highest priority first; re-read
  whenever a worker frees), copies the crate (`rsync --exclude target`), applies the genes, runs
  `w11/tools/measure.sh` with two lane work dirs (the machine-wide slot lock still applies), probes the frame
  (`frame.py`) and records each trial in `results.jsonl` and the shared ledger
  (approach `gene-harvest`, dedupe key `0x22a10-w12-20a1ae9-gene-<trial>-v1`).
- `frame.py <unstripped.so>`: r10-offset probe of `admin_cto::execute` vs the original (first store
  offset: original -2344 = `[r10-0x928]`, main -2288 = `[r10-0x8f0]`; multiset overlap of r10 offsets).
- `table.py <results.jsonl> <genes-cto.json> [<table.md>]`: writes the gene table that the stitchers read,
  `pump-main-swarm/w11/genes-cto.json`.
