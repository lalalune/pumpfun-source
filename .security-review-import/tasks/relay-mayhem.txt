5. Newly visible residual issue
Potential native-output credit diversion/incomplete L-12 remediation: swap paths synchronize the input native ATA but never call sync_native_if_needed on the output ATA. If the output mint is WSOL, direct lamports sent to the output ATA are not reflected in its token amount, so they are excluded from the actual-balance distribution. Closing that ATA can then refund those lamports to the relayer/signer rather than beneficiaries. This is source-visible and not covered by the committed tests; it warrants a targeted WSOL-output test before treating the unsolicited-asset policy as complete.
Also, legacy programs/donation-relay/src/handlers.rs still contains the old donation and settlement logic, but lib.rs at 147e122 wires executable entrypoints through donation_handlers and settlement_handlers. That stale unlinked model should not be treated as a live residual path without separate reachability evidence.

None of this establishes remediation of the current Pump source or deployed programs.
