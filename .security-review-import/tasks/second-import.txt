S2-M01: new Main MEDIUM finding
Suggested title:
M-15 — Permissionless foreign-mint claims can poison Main’s shared cashback counter
The vulnerability is present in the current Pump source:
programs/pump/src/token_incentives/claim_token_incentives.rs:130-142
user is an AccountInfo, not a signer.
The accumulator PDA is derived from that nonsigning user.
The caller supplies the quote mint and token program.
programs/pump/src/token_incentives/claim_token_incentives.rs:304-347
Nonnative claims accept either SPL Token or Token-2022.
The source ATA is derived for the supplied mint, with no recognized-reward-mint restriction.
The entire token balance is transferred to a token account whose decoded owner must equal the victim.
Line 347 then records the raw amount in shared cashback statistics.
programs/pump/src/token_incentives/volume_accumulator.rs:180-195
Every nonnative mint shares total_stable_cashback_claimed.
Lines 188-192 use checked_add(amount).expect(...); overflow aborts the claim.
Native claims use the separate counter at lines 181-186 and are not poisoned by this path.
The attack is therefore valid against current source: an attacker funds the victim-accumulator ATA for an attacker-created mint with u64::MAX - C raw units, invokes the permissionless claim using a victim-owned receiving account, and drives the shared counter to u64::MAX. Subsequent positive nonnative claims panic and roll back, including their token transfer. This is targeted availability loss, not theft.
The victim can close and recreate the accumulator:
programs/pump/src/token_incentives/claim_token_incentives.rs:353-356 requires the user’s signature for closure.
programs/pump/src/token_incentives/init_user_volume_accumulator.rs:9-19 permits reinitialization.
That recovery resets accounting and can forfeit pending incentive rights, supporting MEDIUM, not HIGH or CRITICAL.
Recommended wording should request per-mint counters and nonblocking informational statistics. Saturating arithmetic alone prevents the DoS but leaves aggregate raw-unit statistics economically meaningless across unrelated mints.
Current status: vulnerable by source inspection. The imported claim that record_cashback_claim now saturates is false for this working tree.

Affected assets and impact
A permanent delegate’s authority belongs to the token mint, not to the Pump or pool PDA. After administrative approval and pool creation, the delegate can transfer that quote mint from token accounts without the ATA owner’s signature.
Affected holdings include:
Pump bonding-curve quote ATAs and other accounts holding the approved quote mint.
Canonical PumpSwap pool quote ATAs, including quote liquidity and accrued quote-denominated fees. The vaults are created at programs/pump-amm/src/instructions/create_pool.rs:41-44 and used for reserve and fee transfers, for example programs/pump-amm/src/instructions/swap/sell.rs:206-253.
The paired base asset is not directly transferable by the quote mint’s delegate, and PumpSwap’s ordinary base-mint policy rejects this extension. However, the delegate or collaborators can use seized quote value in AMM trades to extract paired base inventory, so impact is not confined to the issuer’s own token. LP withdrawals also depend on both pool vaults at programs/pump-amm/src/instructions/liquidity/withdraw.rs:116-138.
