Title: Reject unsafe launch reserves and immutable reward configurations
Runtime contract fix — launch reserve and supply validation
Files

programs/lalalune/src/lib.rs
programs/lalalune/src/quote_control/state.rs
programs/lalalune/src/quote_control/update_quote_control_mints.rs
Mechanism
set_virtual_quote_reserves, quote-control mint addition, and quote-control reserve updates now reject zero.
init_curve becomes fallible and validates the selected native, global non-native, or controlled override quote reserve before writing curve state.
Shared Global::validate_curve_initial_reserves requires:
selected quote reserves greater than zero;
real token reserves greater than zero;
virtual token reserves strictly greater than real token reserves;
total token supply strictly greater than real token reserves.
Both legacy create and v2 creation invoke the shared validation. Legacy creation therefore can no longer run successfully with incomplete default zero reserve/supply configuration.
Adds InvalidInitialReserves; existing QuoteReservesOutOfRange is reused.
Finding mapping
The deployment review classifies zero non-native quote reserves as new unnumbered MEDIUM and incomplete legacy configuration as new unnumbered LOW.
Neither has a baseline report ID.
This is unrelated to H-01 and H-04, which concern migration liquidity accounting and Token-2022 transfer-fee handling, not initial virtual launch reserves.
Residual limitations
Protection is forward-looking: previously created malformed curves are not repaired.
Administrative setters can still store some incomplete parameter combinations, but subsequent creation rejects them.
Positive and ordered reserves do not guarantee economically sensible pricing, adequate liquidity, or safe deployment configuration.

Mechanism

Requires the canonical reward vault to be owned by the same token program and to be in Initialized, not Frozen, state. This covers accounts frozen before freeze-authority renunciation.

Residual limitations
Existing immutable campaigns with an incompatible mint or frozen vault are not repaired; historical claim behavior remains unchanged.
Mint authority is intentionally allowed for emissions/funding. Reward solvency, issuer economics, and sufficient funding for announced and archived liabilities remain operational responsibilities.
The conservative allowlist intentionally prevents scheduling with otherwise potentially benign extensions outside the six admitted types.
